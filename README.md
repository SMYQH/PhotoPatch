## 🌟 核心特性 (v1.1.2)

1. **免登录授权**：强制 `TAuth` 鉴权状态返回成功状态，任意账户或离线状态均可使用。
2. **跳过未登录与离线检测**：绕过 `useCachedCredentials` 的离线判定分支，防止离线超时失效。
3. **消除校验失败分支**：移除鉴权异常跳转，失败分支自动重定向至成功处理逻辑。
4. **屏蔽升级弹窗**：拦截版本对比逻辑，屏蔽强制升级提醒。
5. **全量遥测与崩溃上报截断**：入口级拦截 + 彻底清空上报域名与接口。
6. **73 款 AI 模型与控制面板全量中文汉化**：主程序核心菜单与状态条目中文化，全部 73 款 AI 深度学习模型全量翻译。
7. **智能环境与绝对路径探测**：内置注册表与系统标准安装路径（`Program Files`）智能探测，解耦当前工作目录依赖，支持任意位置双击即用。
8. **进程冲突与只读保护**：运行时进程占用自动检测与提示，只读属性自动剥除，杜绝文件锁冲突。
9. **现代 Windows 视觉与编码**：原生 UTF-8 代码页与 PerMonitorV2 高分屏 DPI 缩放支持，界面清晰无乱码。

## 🚀 快速上手

1. 安装 [**Photo.msi**](https://1845553482.share.123pan.cn/123pan/87lLTd-k2ZEA)，安装完成后退出程序。
2. 右键选择 **以管理员身份运行** `Photo Patch.exe`（工具会自动探测并定位安装目录）。
3. 勾选 **启用完整中文汉化**（默认已勾选）。
4. 点击 **应用补丁与汉化** 按钮。
5. 看到日志提示全部操作执行完毕后即可退出工具。
6. 打开 Photo 即可正常离线使用中文界面。
7. 如需回退，随时点击 **还原原始备份** 恢复原版文件。

## 🛠️ 构建指南

项目支持在 Linux / WSL 环境下通过 MinGW-w64 交叉编译为原生 Windows 64 位二进制。

### 1. 环境准备

```bash
apt update
apt install -y gcc gcc-mingw-w64-x86-64 binutils-mingw-w64-x86-64
```

### 2. 执行一键构建

```bash
chmod +x build.sh
./build.sh
```

构建产物：

- `Photo Patch.exe`：独立完整单文件 GUI 补丁与全量汉化程序 (v1.1.2)。
- `dup2patcher.dll`：核心补丁动态库 (导出 `load_patcher` / `SearchAndReplace` / `AddMsg`)。
