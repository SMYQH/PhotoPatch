# Photo 逆向学习工程

## 🌟 目标

1. **免登录授权**：强制鉴权函数返回有效状态，任意注册/输入即可自动激活。
2. **跳过未登录检测**：绕过未登录状态与离线过期检查。（未实现）
3. **消除校验失败分支**：移除鉴权失败时的跳转和异常处理逻辑。
4. **屏蔽升级提醒**：拦截新版本更新提示。
5. **彻底禁用遥测**：截断匿名遥测上报入口，抹除遥测服务器地址。

---

## 🚀 快速上手

1. 安装**Photo.msi**，安装完成后确保彻底退出软件。
2. 将编译生成的 `Use.exe` 复制到软件安装根目录下（默认路径为：`C:\Program Files\Topaz Labs LLC\Topaz Photo AI`）。
3. 右键选择 **以管理员身份运行** `Use.exe`。
4. 在界面中点击 **应用补丁** 按钮。
5. 看到日志框提示 `[+] 补丁应用成功！共修改了全部特征点。` 即可退出补丁工具。
6. 打开 Topaz Photo AI，随意输入注册任意账户即可完成离线授权。

## 🛠️ 构建

项目使用 MinGW-w64 工具链进行跨平台交叉编译。

### 1. 环境准备

```bash
apt update
apt install -y gcc-mingw-w64-i686 binutils-mingw-w64-i686 python3
```

### 2. 执行构建

```bash
chmod +x build.sh
./build.sh
```

>    本项目仅为初学者进行逆向学习所用。
